# حساب ماهانه

اپ سادهٔ مدیریت عاید و مصارف ماهانه، مخصوص مبایل.

- عاید و مصرف ثابت یا متغیر
- موارد ثابت ماه بعد خودکار به صورت پیش‌نویس می‌آیند
- قبل از ثبت، اجازه می‌پرسد
- ماه‌های گذشته ذخیره می‌مانند

آدرس: https://sultansharifi.github.io/hesab-mahana/

معلومات فقط در همان مرورگر ذخیره می‌شود.
